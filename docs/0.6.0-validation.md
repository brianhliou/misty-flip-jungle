# MistyJungleFlip 0.6.0 validation

`EvalFile` is empty by default. A valid external JFNN v2 file replaces only
heuristic leaf evaluation. A failed load clears the previous net, reports
`info string error EvalFile`, and refuses subsequent searches with
`bestmove (none)`. Loading a valid file or explicitly clearing `EvalFile`
restores search. `ucinewgame` preserves the selected evaluator and load-error state.
No trained weights are distributed with this release.

## Inference and search contract

The inference port retains the int16 incremental feature transformer, int8
per-row dense quantization, int32 dot products, rounding and evaluation scale.
The dense inference implementation differs from its reference only in module
imports. JFNN v2 starts with `JFNN`, then five little-endian u32 values
`[2, 384, H, 16, 32]`. The payload is little-endian f32, in order:
`FT[384,H]`, transformer bias `[H]`, `W1[16,2H]`, `b1[16]`,
`W2[32,16]`, `b2[32]`, `W3[1,32]`, `b3[1]`.
The loader validates magic, version, shape, exact length, finite weights and
safe transformer accumulator bounds. Width must be 1 through 4096.

Features contain only public revealed pieces, covered-square markers, public
unrevealed piece counts, the no-progress clock, turn and first-flip color
binding. Both absolute-seat accumulators encode colors relative to their seat.
Live heuristic leaves use repeat count 1, as search adjudicates repeated
positions before reaching evaluation. Utility is `2 * sigmoid(logit) - 1`,
clamped to ±0.95 by inference and to ±0.85 by the existing win-distance search.
No ChanceMix is enabled.

Tablebase probing and terminal adjudication take precedence over either
heuristic. Star1 flip enumeration, capture quiescence, contempt, repetition,
move ordering, tie-breaking and weak-play policy use the shared search.
Every real child pushes and pops the incremental evaluator, including chance
outcomes and quiescence captures. Pop happens before propagating a node-budget
or deadline abort. Each search and each noisy depth pass starts from a fresh
root accumulator.

The existing limits remain unchanged: the node that exceeds the budget is
counted, and deadline checks retain their 512-node countdown. A `go` without
`movetime` has no deadline; `movetime 0` is an immediate deadline in this engine.
Noise always finishes its depth-one pass, then respects the shared limits for
later passes. UCI node statistics retain 0.5.4's accounting, which excludes the
separately budgeted exact-tie pass. This benchmark pins `JF_TIE_SEED=0`.

The wasm package changes version only. Its shared search still uses classical
evaluation and never includes the NNUE loader or inference modules.

## Regression checks

- Five UCI fixtures were recorded from the unmodified 0.5.4 executable before
  this port, with the built-in two-piece tablebase, `JF_TIE_SEED=0` and 5,000
  nodes. Default, explicitly empty and `<empty>` settings match their bestmove,
  centipawn score, completed depth and node count. The existing classical and
  weak-play fixtures also remain in place.
- Synthetic and external nonconstant nets each compare quantized inference
  against the full-refresh float reference on 600 legal public positions.
  The reference tolerance is 0.25 logit units. Observed maximum errors were
  0.006348491 for synthetic weights and 0.07033968 for the external net.
- Synthetic and external hidden-information checks swap two face-down
  identities, then require identical evaluation bits and fixed-node search
  results. Deliberately exposing the swapped identities changes the logit.
- Instrumented search checks each incremental push and pop against a fresh
  quantized refresh, through reveals, captures, iterative deepening, noisy
  passes, root tie-breaking and budget/deadline aborts. Stateless fresh
  quantized search must match incremental moves, score bits, depth and nodes.
- Synthetic checks pin the utility scale, chance-leaf use, win-band clamp,
  tablebase distance scores, terminal wins, no-progress draws and seeded
  repetition precedence.
- UCI checks cover paths containing spaces, case-insensitive `EvalFile`,
  persistence, clearing, missing/malformed/unsafe files, blocked searches and
  recovery, deterministic net searches, node/time limits, and seeded noisy
  choices across evaluator switches. Header/weight tests reject invalid
  versions, widths, shapes, lengths, NaN, infinity and unsafe int16 bounds.

## Reproducing validation

From the workspace root:

```sh
env -u MISTY_FLIP_JUNGLE_TEST_NET cargo test --release --workspace -- --nocapture
MISTY_FLIP_JUNGLE_TEST_NET=/path/to/evaluation.jfnn cargo test --release --workspace -- --nocapture
cargo clippy --workspace --all-targets -- -D warnings
wasm-pack build jungle-flip-wasm --target web --release
```

Tests never bundle or copy external weights. When the variable is unset, three
checks print `SKIP trained-net check: MISTY_FLIP_JUNGLE_TEST_NET is unset` and
return early; Cargo reports these as passes. An explicitly configured bad path
fails the external checks. Synthetic files are generated in the system temp
directory and removed after each test. `*.jfnn` is ignored by Git.

The default-feature workspace build also checks the Python-facing crate.
The PyO3 build helper supplies extension linker flags, while integration-test
executables link the configured Python library on macOS/Linux because release
LTO can retain Python exports from the rlib. Rust unit tests omit extension
exports. The helper was already a transitive dependency; no inference dependency
was added. Existing lint findings received mechanical fixes to pass the strict
workspace Clippy check without changing traversal or evaluation arithmetic.

| Release workspace configuration | Cargo passes | External checks skipped | Failures |
| --- | ---: | ---: | ---: |
| Test-net variable unset | 89 | 3 (86 checks executed) | 0 |
| Test-net variable set | 89 | 0 | 0 |

Totals: 45 UCI-package tests, 12 wasm-core tests and 32 native-core tests;
zero doctests. Both runs include every workspace member with default features.
Clippy passes with warnings denied. The documented `wasm-pack` release build
also passes, including binding generation and `wasm-opt`; a scan of the resulting
wasm finds no JFNN loader signature. Build tooling used a temporary cache.

## Local benchmark

Measured on 2026-11-08, on this arm64 Mac running macOS 27.0.1, with Rust 1.92.0
and the release profile (LTO, one codegen unit). The external round-six JFNN net
has SHA-256 `b9a51b57f19f34cea8c88694282ee161ec32b9ffa22ed13bc20c64abf50f9b80`.
Weights remain external and unpublished.

```sh
cargo build --release -p jungle-flip-engine
MISTY_FLIP_JUNGLE_TEST_NET=/path/to/evaluation.jfnn python3 scripts/bench-nnue.py
```

The script runs one warmup and takes the median of five searches per cell,
using the UCI engine's search-only integer-millisecond timings. Startup and net
loading are excluded. Each search consumes budget + 1 nodes. No wall-clock
limit or noise is set; only the built-in ≤2 tablebase is present. Results vary
with host load, and millisecond rounding particularly affects the 50k samples.

| Position | Classical nodes/s at 50k | Net nodes/s at 50k | Net ms at 1M | Net ms at 2.5M |
| --- | ---: | ---: | ---: | ---: |
| Opening | 3,333,400 | 1,315,816 | 652 | 1,547 |
| Midgame | 2,500,050 | 1,315,816 | 659 | 1,789 |
| Revealed | 1,923,115 | 1,020,429 | 644 | 1,588 |

The exact FENs and measurement procedure are in `scripts/bench-nnue.py`.
These are throughput and latency measurements.
